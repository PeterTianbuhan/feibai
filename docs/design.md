# 设计

这里只记 Peter 定下的事。标着「待定」的是 Fable 的提议，Peter 还没点头。

## 玩法

- 只有一个键。笔锋绕着一个点转圈，点一下离手，沿切线直飞出去，落进另一个点的圈里就被接住。
- 转一圈用多久是固定的，不随落点、不随进度变。玩家要能练出手感。
- 落得准（「妙」）只有奖励，没有惩罚。
- 难度分档，开局选。同一档里手感数值全程不变。
- 难不难只看布局：下一个圈多远、多小、在什么角度。

## 探索

- 世界是背景，玩家跟着圈走出去看它。走得越远，看到的地方越多，也越难。
- 到过的大点可以当新的起点。飞空了不用从头来。
- 地图就是玩家自己走出来的那幅画：到过的地方有笔迹和景，没到过的是空白。
- 到了某处景观附近有彩蛋，收进一本见闻册。见闻册里放世界观，也放别的想放的东西。

## 不止一个世界

- 水墨只是其中一个。别的世界有别的场景和画法，比如 Peter 的 T3 主题那种粉紫到橙的黄昏天、电线、星星。
- 墨不一定一直是墨，也不一定一直在耗，可以变。

## 怎么做

- 当正式项目做，往成品追，不是一个随手的单文件。
- 有想法就派代理去做。Peter 不一轮一轮试玩。
- 规矩从少的开始，出了问题再加。

## 待定（Fable 的提议）

**世界是什么。** 一个世界是一套东西：底（宣纸、黄昏的天）、笔（留下的线是什么）、点长什么样、景、声音、资源规则、布局规则、见闻。引擎不认识「墨」，只认识「这个世界的资源规则」。

**资源规则各不相同。** 这是对「墨可以变」的理解。水墨里墨越写越干，到新的点才蘸满。黄昏里不耗东西，只有飞空才结束，是最轻松的一个世界。以后的世界可以各有各的规则。

**世界怎么连。** 一张连续的大地图，每个人看到的是同一张。从水墨的中心出发，往某个方向走到头有一处渡口，过去就是另一个世界，底和笔跟着换。

**先做哪两个。** 水墨和黄昏。两个差别大的世界同时做，才知道哪些东西该放在引擎里，哪些归世界自己。之后的候选：极夜（极光）、速写本（钢笔线加淡彩）。每加一个世界是一个代理的一份活。

**布局。** 大点和区域的位置由固定种子定。大点之间的小点按区域规则生成，沿着河岸、山脊、电线这类景摆，这样跳过去的那一笔正好把景画出来。有岔路：好走但绕远，或者难走但近、通向藏起来的景。每一跳的难度按「离手的时间窗有多宽」来算。

**不靠人试玩怎么验收。**
- 试玩机器人：规则部分是确定的，机器人按「离手时机有几十毫秒误差」的人来玩，每条路跑几千遍，报每一跳、每条路的通过率。难度用这个数字定。
- 截图：每个世界在固定时刻、手机和电脑两种尺寸各截一张，由没参与制作的代理对照画法说明来看。
- Peter 想玩的时候再玩，不排进流程。

**第一版做到哪。** 两个世界，每个三片区域、十来处景和见闻；三档难度；地图和从大点出发；进度存在浏览器里；有声音；手机一根手指能玩；能发给朋友的一个链接。没有账号，没有联机。

**技术。** 浏览器，Vite + TypeScript + Canvas 2D，不用游戏引擎。现有代码就是 Canvas，体积小，手机上秒开。
