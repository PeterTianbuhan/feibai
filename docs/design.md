# 设计

这里只记 Peter 定下的事。标着「待定」的是 Fable 的提议，Peter 还没点头。

## 导向

- Peter 想在这个项目里看到代理的审美。这在很大程度上是代理创造的世界，他只给一点点思路。
- 做一个世界的代理要对这个世界负责。它是这一方世界的主人和造物主，这个世界是什么样子，它有最高的权限来定。给每个世界定主题，只是为了尽量不重复，不是为了限制。
- 音乐是重要组成部分。
- 每个世界做完之后还要再迭代几轮。每一个世界，都要像一个创作者认真对待、精心打磨的代表作。

## 名字

- 叫《飞白》。原来叫《一笔》，Peter 觉得太朴素。
- 名字是因为和 Fable 谐音才选的，不是风格的要求。Peter 发现很多页因为这个名字在往国风靠拢，他个人对国风不那么感兴趣。

## 玩法

- 只有一个键。笔锋绕着一个点转圈，点一下离手，沿切线直飞出去，落进另一个点的圈里就被接住。
- 转一圈用多久是固定的，不随落点、不随进度变。玩家要能练出手感。
- 落得准（「妙」）只有奖励，没有惩罚。
- 难度分档，开局选。同一档里手感数值全程不变。
- 难不难只看布局：下一个圈多远、多小、在什么角度。

## 探索

- 世界是背景，玩家跟着圈走出去看它。走得越远，看到的地方越多，也越难。
- 到过的大点可以当新的起点。飞空了不用从头来。
- 这是代理造好的世界，人用这个玩法进去探索。它不太像创作。能找到让玩家创作的办法也很好，但不是前提。
- 走过的轨迹不一定到处留着，一直留着可能有问题。留不留、留什么，由每个世界自己定。
- 地图是玩家已经发现的世界：到过的地方显出来，没到过的是空白。
- 到了某处景观附近有彩蛋，收进一本见闻册。见闻册里放世界观，也放别的想放的东西。

## 不止一个世界

- 水墨只是其中一个。别的世界有别的场景和画法，比如 Peter 的 T3 主题那种粉紫到橙的黄昏天、电线、星星。
- 世界排成一本画册：每个世界是一页，有自己的纸。世界之间靠渡口相连，像高维的连接，不拼成一张大图。
- 这个游戏的点子应该围绕着世界。之后再补一批点子。
- 要的是有趣的世界设计。设计一批，一起做出来试，见 `docs/worlds.md`。
- 要能部署，朋友在浏览器里玩，进度能记住。
- 每个世界有一种会消耗、能补充的资源。墨是水墨世界的，别的世界找自己的，比如电量。
- 每个世界有自己独特的环境机制，新奇的乐趣从这里来。
- 一个世界的探索度到了某个值，有额外的奖励。

## 怎么做

- 当正式项目做，往成品追，不是一个随手的单文件。
- 有想法就派代理去做。Peter 不一轮一轮试玩。
- 规矩从少的开始，出了问题再加。

## 待定（Fable 的提议）

**每个世界按同一张单子来设。** 五样：底和笔（宣纸和墨线、黄昏的天和电光）；资源（叫什么、怎么耗、在哪补）；一个环境机制；景和见闻；探索奖励。引擎不认识「墨」，只认识「这个世界的资源」和「这个世界的环境机制」。一个世界是一个目录，也是一个代理的一份活。

**环境机制一个世界只放一个。** 要守三条：还是只用一个键；结果是确定的，机器人能玩；一眼能看懂。水墨是第一个世界，不放环境机制，只教玩法。

**画册怎么连。** 水墨在中间，四周远处有几个渡口，各通一页。别的页之间也有渡口。同一页可以从不同的渡口进去，落点不同。地图、画、见闻册是同一本册子：每个世界一个对开页，一边是玩家在这一页发现的世界，一边是这一页的见闻。

**探索奖励。** 每个世界算自己的探索度（到过的点和景占多少）。到一定比例给东西，比如：一处藏起来的景、见闻册里这个世界的一章、把这个世界的笔带去别的世界用。

**布局。** 大点和区域的位置由固定种子定。大点之间的小点按区域规则生成，沿着河岸、山脊、电线这类景摆，跳过去的路就顺着景走。有岔路：好走但绕远，或者难走但近、通向藏起来的景。每一跳的难度按「离手的时间窗有多宽」来算。

**不靠人试玩怎么验收。**
- 试玩机器人：规则部分是确定的，机器人按「离手时机有几十毫秒误差」的人来玩，每条路跑几千遍，报每一跳、每条路的通过率。难度用这个数字定。
- 截图：每个世界在固定时刻、手机和电脑两种尺寸各截一张，由没参与制作的代理对照画法说明来看。
- Peter 想玩的时候再玩，不排进流程。

**第一版做到哪。** 水墨加 `docs/worlds.md` 里做出来好玩的那几页；三档难度；地图和从大点出发；进度存在浏览器里；有声音；手机一根手指能玩；能发给朋友的一个链接。没有账号，没有联机。

**技术。** 浏览器，Vite + TypeScript + Canvas 2D，不用游戏引擎。现有代码就是 Canvas，体积小，手机上秒开。
